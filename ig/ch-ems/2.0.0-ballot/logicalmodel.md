## Logical Model

The logical model represents the Emergency Medical Services protocol as an abstract data model. Each section of the model includes a [**Model Map**](ConceptMap-EmsMission2Fhir.md) that defines how its data elements are mapped to the [FHIR document](document.md) structure.
